# examples for fitsnap ASE tools
These are examples on how to use the FitSNAP JSON to ASE converter
note that it expects you have installed the fitsnap_ase_tools
module with pip or have added it to your python path.
See the README in the fitsnap_ase_tools directory (not examples)
on how to install


------------------------------------------------------------
These examples are set up to run in a folder contatining

`JSON/group_folder/*.json`

fitsnap structure files.


## Basic usage: read in JSON Database as ASE atoms list with metadata

See:

`simple_example.py`

it will operate on the small sample JSON folder in this example folder.
